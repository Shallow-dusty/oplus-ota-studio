# v0.1 Product Convergence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop expanding backend internals and converge OPlus OTA Studio into a private-trial v0.1 build that is honest about evidence limits.

**Architecture:** The backend core is now treated as feature-complete for v0.1 unless a real-device run exposes a blocking bug. Remaining work is product validation, UI state confidence, and release packaging evidence.

**Tech Stack:** Kotlin, Jetpack Compose, Room, WorkManager, DataStore, OkHttp, MockWebServer, Android emulator/device testing, Gradle release builds.

---

## Scope Decision

Do not add new backend safety patches unless they are required by one of these
three v0.1 outcomes:

1. A user can look up an OTA package or see an honest experimental/no-evidence
   result.
2. A user can download, resume, verify transfer integrity, and find the ZIP in
   Downloads.
3. A private-trial APK can be built, installed, launched, and explained with
   clear known limitations.

## Task 1: Evidence Path

**Files:**
- Modify only if evidence changes: `core-ota/src/test/resources/fixtures/`
- Modify only if evidence changes: `docs/superpowers/specs/2026-06-29-oplus-ota-studio-design.md`
- Modify: `docs/progress.md`
- Optional evidence log: `docs/evidence/ota/`

- [ ] Connect a real OnePlus/OPlus device, or explicitly record that no device
      is available for this pass.
- [ ] Run the existing app or test harness lookup path with the real profile.
- [ ] If lookup succeeds, commit a redacted `captured-real-*` or
      `replayed-real-profile-*` fixture and flip only proven spec fields from
      uncertain to proven.
- [ ] If lookup still fails due to endpoint/network behavior, do not expand the
      backend. Record the blocker and keep v0.1 labeled experimental.
- [ ] Commit evidence-only docs/fixture changes separately from code.

Verification:

```powershell
.\gradlew.bat :core-ota:testDebugUnitTest
.\gradlew.bat test lintDebug :app:compileDebugAndroidTestKotlin
```

## Task 2: UI State Confidence

**Files:**
- Modify: `feature-lookup/src/main/`
- Modify: `feature-downloads/src/main/`
- Test: `feature-lookup/src/test/`
- Test: `feature-downloads/src/test/`
- Modify after verification: `docs/progress.md`

- [ ] Add focused tests for lookup state rendering/presentation: incomplete
      profile, consent required, loading, package found, no update, network
      error, server/schema error, and experimental evidence disclosure.
- [ ] Add focused tests for download state rendering/presentation: queued,
      running, paused, retrying, verifying, verified, unverified, canceled,
      checksum mismatch with expected/actual hashes, and final file path/copy
      actions.
- [ ] Extract a small presentation mapper only if existing UI code cannot be
      tested directly.
- [ ] Do not add screenshots unless the pure state tests show a real gap that
      only screenshots can catch.
- [ ] Commit lookup UI coverage and download UI coverage as separate commits
      if they touch different feature modules.

Verification:

```powershell
.\gradlew.bat :feature-lookup:testDebugUnitTest :feature-downloads:testDebugUnitTest
.\gradlew.bat test lintDebug :app:compileDebugAndroidTestKotlin
```

## Task 3: Private-Trial Release Cut

**Files:**
- Modify: `docs/release.md`
- Modify: `docs/progress.md`

- [ ] Build an unsigned release APK.

- [ ] Verify `apksigner` output and install/launch the APK on the newest

- [ ] Record APK version, signing verification, install result, launch result,

Verification:

```powershell

& "$env:ANDROID_HOME\build-tools\37.0.0\apksigner.bat" verify --print-certs app\build\outputs\apk\release\app-release.apk
.\gradlew.bat test lintDebug :app:compileDebugAndroidTestKotlin
```

## Stop Rules

- Stop adding backend internals after Task 1 unless a failing validation command
  points to a concrete production bug.
- Stop after Task 2 if UI state coverage passes and no user-visible state is
  missing.
- Stop after Task 3 with a private-trial artifact plus a known-limitations note;
  v0.2 carries live endpoint verification if v0.1 remains fixture-backed.
