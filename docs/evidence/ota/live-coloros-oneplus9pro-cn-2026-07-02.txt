OPlus OTA Studio live ColorOS OTA evidence
Date: 2026-07-02
Branch: feat/backend-core

Purpose
-------

Record the first successful phone-side ColorOS component OTA lookup path after
the earlier PC-side legacy endpoint replay failed. This evidence proves the
OnePlus 9 Pro CN replay profile can query the live ColorOS component endpoint
from a physical device and return the expected package metadata.

Important limitation:

    This is a live phone-side endpoint query using a replay/spoofed OTA build
    string from the known successful OnePlus 9 Pro CN chain. It is not a pure
    "current installed build asks whether it has an update" result. The app
    should continue to label this package evidence as replayed-real-profile,
    not live-verified.

Conclusion
----------

The earlier blocker was not app installation. The production gap was that the
app still used the stale legacy OTA endpoint and did not pass ColorOS request
hints needed by the live component endpoint. The app now installs on the
physical OnePlus 9 Pro, launches, and its guarded instrumentation path can
query the live ColorOS component OTA endpoint successfully.
